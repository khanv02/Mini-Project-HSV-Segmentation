# Danh mục tutorial

Chọn hướng dẫn theo việc bạn muốn hoàn thành. Phần giải thích thuật toán và giới hạn được đặt riêng
trong [danh mục tính năng](../features/README.md).

| Mục tiêu | Tutorial | Kết quả nhận được |
|---|---|---|
| Làm quen với giao diện và luồng cơ bản | [Bắt đầu sử dụng](../getting-started/README.md) | Mở nguồn, tạo mask và xuất kết quả |
| Chọn vùng sáng hoặc tối trong ảnh xám | [Ảnh xám và Otsu](grayscale-manual.md) | Mask Manual hoặc Otsu với polarity rõ ràng |
| Lưu lớp minh họa cho báo cáo | [Save Overlay](save-overlay.md) | PNG đúng với Overlay đang hiển thị |

Tutorial tập trung vào thao tác. Khi cần hiểu “tính năng dùng để làm gì”, hãy quay lại
[danh mục tính năng](../features/README.md).
